# 微信渠道接入指南（从本机到评委手机）

> 配套:`server/server.js`(webhook 已支持验签/关注欢迎/语音转文字/防重) + `wechat-test.html`(渠道模拟器)
> 目标:让评委在**自己的微信里**给公众号发一句话,收到同一套风控/知识/适老引擎的回复。

---

## 〇、最快路径:公众平台测试号(30 分钟跑通,推荐先做)

测试号无需注册公众号、无需认证,扫码即得,接口权限与正式号一致(够演示用)。

1. 打开 `https://mp.weixin.qq.com/debug/cgi-bin/sandboxinfo?action=showinfo&t=sandbox/index`,用个人微信扫码进入测试号。
2. 记下页面的 `appID`、`appsecret`(本 demo 不用,忽略)与 **接口配置信息**。
3. 本机启动服务(带 Token):

   ```bash
   cd D:\gonghang-demo
   WECHAT_TOKEN=icbc2026 node server/server.js
   # Git Bash 写法;PowerShell 用:$env:WECHAT_TOKEN="icbc2026"; node server/server.js
   ```

4. 内网穿透(见第二节),得到公网地址,例如 `https://xxxx.cpolar.io`。
5. 测试号页面的「接口配置信息」填写:
   - URL: `https://xxxx.cpolar.io/wechat/webhook`
   - Token: `icbc2026`
   - 消息加解密方式: **明文模式**
6. 点「提交」→ 微信服务器会 GET 你的 webhook 验签并回显 echostr → 显示"配置成功"。
7. 用个人微信扫描测试号下方的二维码关注 → 发消息 `查一下余额` → 收到大白话回复;发送 `群里说投养老项目每月返大钱稳赚` → 触发风控拦截话术。

## 一、正式订阅号/服务号接入

流程与测试号相同,差别仅在入口:公众平台 → 设置与开发 → 基本配置 → 服务器配置。
个人主体可注册**订阅号**,具备自动回复消息权限,足够演示。配置时同样选择**明文模式**(兼容/安全模式需 AES 解密,演示不需要)。

## 二、内网穿透(三选一)

微信服务器要能访问你本机的 `8787` 端口,需要穿透工具:

| 工具 | 特点 | 命令 |
|---|---|---|
| **cpolar** | 国内直连快,免费套餐够用 | 官网注册 → 下载 → `cpolar http 8787` |
| **natapp** | 老牌,免费隧道随机域名 | 官网注册购免费隧道 → `natapp -authtoken=xxx` |
| **cloudflared** | 免注册快速试用 | `cloudflared tunnel --url http://localhost:8787` |

得到形如 `https://xxxx.tunnel.com` 的公网地址后,第〇节第 5 步的 URL 前缀换成它即可。
**注意**:免费隧道域名每次重启会变,演示当天重新生成并更新公众号后台;正式路演建议 cpolar 保留套餐固定域名。

## 三、本地无穿透验证(模拟器)

打开 `http://localhost:8787/wechat-test.html`(必须通过 node 服务访问):

- 「服务器验证」按钮:按微信规则(`sha1(sort(Token,Timestamp,Nonce))` 对比 signature)做 GET 验签,正确签名回显 echostr、错误签名返回 403 —— 与真实配置流程一致。
- 「快捷场景」:文本、**语音消息(带 Recognition 转写文字)**、关注事件(自动欢迎语)、图片消息(兜底话术),全部以真实 XML 报文走一遍 webhook。
- 右侧「渠道消息日志」展示每条消息的意图与风控结果,路演时可投屏。

## 四、消息处理能力(已实现)

| 消息类型 | 行为 |
|---|---|
| 文本 | 意图路由 → 风控/知识/业务 Agent → 适老化回复 |
| 语音 | 取微信 `Recognition` 语音转文字结果进入引擎;无转写则温和引导 |
| 关注事件 subscribe | 自动发送欢迎语(含使用引导) |
| 取消关注 | 静默返回 success |
| 图片/其他 | 兜底话术引导用户打字或发语音 |
| 重复消息 | 按 MsgId 去重(微信 5 秒超时会重试 3 次,避免回复三遍) |

## 五、常见问题排查

| 现象 | 原因与处理 |
|---|---|
| 后台提交"Token 校验失败" | 公众号 Token 与 `WECHAT_TOKEN` 不一致;或穿透地址不是 80/443 公网可达。先开 `wechat-test.html` 用"正确签名验证"确认服务端 OK,再查穿透 |
| 配置成功但发消息无回复 | 看本服务控制台/`/api/wechat-log` 是否收到 POST;没收到 → 穿透断了或 URL 路径写错(必须是 `/wechat/webhook`);收到但回复空 → 看控制台报错 |
| 同一条消息回复多次 | MsgId 去重只挡 2 分钟内的重试;若穿透延迟 >5 秒,微信会重试属正常,检查网络 |
| 演示当天域名变了 | 免费隧道重启即换域名,公众号后台改一下 URL 重新提交即可 |

## 六、演示建议(路演脚本 30 秒片段)

1. 投屏本服务控制台(或 `/api/wechat-log`)。
2. 评委/队友微信发"我孙子让我转钱给他买房,可我听说有个项目利息更高"→ 公众号回复温和风控提示,日志显示 `风控拦截`。
3. 长辈端 H5 与微信渠道同一引擎 —— 一句话收束:"**一次接入,全渠道守护**"。
