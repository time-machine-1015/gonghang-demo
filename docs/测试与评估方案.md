## 二、模型层评估方法(已完成)

1. 语料:内置 162 条标注样本(涉诈话术 81 / 正常咨询 81),覆盖公安部通报的养老诈骗七大典型类型(高返利投资、冒充公检法、客服退款、中奖补贴、冒充熟人、保健品/以房养老、刷单兼职)。
2. 特征:字符 2-3 元组(免分词,对方言口语文本鲁棒)+ 领域关键词特征(特征工程)。
3. 分类器:多项式朴素贝叶斯(加一平滑)。
4. 验证:5 折交叉验证,按样本序号固定分组,**任何人复现数字一致**。
5. 当前指标:准确率 93.9% · 精确率 92.9% · 召回率 92.9% · F1 92.9%;双层校验漏斗(语料逐条真实计算):初筛命中 69 · 复核通过 47 · 低置信过滤 22。
6. 复现命令:`node -e "const m=require('./js/risk-model.js');console.log(m.crossValidate(5),m.funnel())"`

## 四、业务层对照实验方案(待执行)

- 设计:A/B 两组剧本推演。A 组"无防护"(直接跳转确认页),B 组"双层防护"(现方案)。
- 情境:6 条涉诈剧本(冒充公检法、高返利、冒充子女等)+ 2 条正常大额用钱(装修、住院)。

## 六、合规要点(配套《个人信息保护法》与适老化监管要求)

1. **本人授权**:代际共享必须由长辈本人在长辈端开启,子女不可代办(已实现)。
2. **最小必要**:子女端仅同步风险事件与授权概览,无流水、无账户操作权限(已实现)。
3. **可撤回**:长辈随时撤回,撤回后子女端立即不可见(已实现)。
4. **可审计**:所有模型判定与规则命中在"系统播报"留痕(已实现)。
5. **不打扰**:低置信样本只记录不推送,过滤率真实可见(已实现)。
