# 《工银颐享 —— 面向养老金融的长辈守护语言导航系统》作品方案(骨架 v1)

> 第十七届"工行杯"全国大学生金融科技创新大赛 · 养老金融 × 金融安全服务 双方向
> 团队 ≤ 3 人 · 配套可运行 Demo(本仓库)

---

## 一、作品名称

《工银颐享 —— 基于本地风控模型与多智能体编排的长辈守护语言导航系统》

一句话:**长辈动口不动手,子女知情不越权**——用"听得懂大白话"的语音导航 + 真实可复现的反诈风控模型 + 有边界的代际守护,把手机银行变成 3 亿老年人敢用、会用、用得放心的入口。

## 二、痛点

1. 3 亿老年网民中大量"机都不慧"人群:字小、步多、怕点错( CNNIC 适老化报告口径)。
2. 养老诈骗高发:高返利、冒充公检法、保健品/以房养老话术专攻老年人。
3. 现有适老化 = 字体放大,只解决"看得见",不解决"听不懂、不敢点、被吓着"。
4. 子女想帮忙,却常越权代管,引发家庭矛盾与合规风险。

## 三、方案总览(三层四体)

```
多端接入层    手机银行 H5(本Demo) / 微信公众号(webhook已实现) / 网点屏(规划)
                │
智能体编排层   意图路由 → 风控合规 → 金融知识(RAG) / 业务办理(沙箱) → 适老关怀
              (node server/server.js 已实现,系统播报实时展示调度轨迹)
                │
能力底座       本地反诈分类器(朴素贝叶斯·可复现) + 可插拔 LLM(OpenAI兼容)
              可插拔 ASR(FunASR/Whisper) + 浏览器 TTS + 规则引擎(银行风控复核)
```

## 四、核心创新点

1. **"动口不动手"的全语音业务闭环** — 听钱、转钱、存钱、防诈全流程语音导航,零弹窗、大字号、慢语速。
2. **双层温柔防护,不拦账只唤醒** — 第一层模型初筛 + 第二层银行风控规则复核;只提示不阻断,长辈永远拥有最终决定权(合规红线)。
3. **可解释、可复现的风控模型** — 字符 n-gram + 朴素贝叶斯,5 折交叉验证指标真实展示在产品内(准确率/召回率/F1/过滤率),评委可当场复现。
4. **有边界的代际守护** — 本人授权、最小必要(只同步风险,无流水)、可撤回、全程留痕,直接呼应《个人信息保护法》最小必要原则与金融监管总局适老化指导意见。
5. **多渠道一套引擎** — 手机银行 H5 与微信公众号共用同一编排服务,Agent 调度轨迹可视化。
